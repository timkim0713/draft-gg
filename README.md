# DeepLoL Comp AI (롤 5:5 솔로랭크 픽창 & 라이브 인게임 AI 분석기)

DeepLoL 및 OP.GG 감성의 미니멀 다크 UI를 적용하고, **LLM AI 모델(Gemini)** 및 **Riot Spectator API**를 연동하여 소환사의 실시간 진행 중인 게임과 픽창 조합을 정밀 분석하는 웹 애플리케이션입니다.

---

## 1. 실행 방법

```bash
cd lol-comp-web
npm install
npm run dev
```

브라우저에서 `http://localhost:5173` 접속.

---

## 2. 핵심 기능

### (1) LLM AI 모델 기반 심층 분석 (AI Coach Engine)
- 프로팀 수석 분석관 시각에서 10개 챔피언 조합의 상성, 5:5 한타 연계력, 사이드 라인 스플릿 위험도를 자연어 및 정량 데이터로 브리핑.
- Gemini 2.5 Flash API 실시간 호출 지원 (우측 상단 [설정]에서 API Key 등록 가능).
- API 키가 없는 상태에서도 즉시 고정밀 분석 엔진이 동작하여 끊김 없이 사용 가능.

### (2) Riot Spectator API 라이브 인게임 조회 (OP.GG / DeepLoL 방식)
- 상단 검색창에 `소환사명#태그` (예: `Hide on bush#KR1`) 입력 시, Riot API를 통해 현재 진행 중인 게임의 10개 챔피언을 자동 감지하여 5:5 블루/레드 진영에 즉시 세팅.
- [Faker], [Chovy] 등의 원클릭 샘플 프리셋 제공.

### (3) 미니멀 다크 UI (이모지 완전 배제)
- DeepLoL 특유의 텍스트 중심 미니멀 다크 스타일.
- 이모지를 일절 사용하지 않고 명확한 텍스트 배지와 라인 아이콘으로 가독성 극대화.

### (4) 5:5 한타 및 교전 집중 분석
- 블루팀 vs 레드팀 5:5 정면 힘싸움(Front-to-Back) 승리 요인.
- 블루팀 진입 및 타겟팅 우선순위 vs 상대팀 위협 스킬 및 카운터 주의점.

### (5) 3단계 운영 승리 플랜 (Macro Roadmap)
- 초반 (0~14분): 라인전 주도권 및 첫 공허 유충 vs 첫 드래곤 선택.
- 중반 (15~25분): 1-3-1 스플릿 vs 5:5 강제 한타 매크로 스타일.
- 후반 (25분+): 바론 버스트 및 넥서스 엔딩 팁.

### (6) 라인별 1:1 맞대결 상성 및 코칭 팁
- 탑, 정글, 미드, 원딜, 서폿 라인별 초반 주도권 우열 및 핵심 팁.
