# 🎮 LoL Comp Coach (웹 기반 롤 5:5 솔랭 조합 분석기)

OP.GG 감성의 세련된 다크 테마 UI를 적용하여, 롤 픽창이나 로딩창에서 **우리 팀과 상대 팀의 조합 파워, 한타 유불리, 3단계(초/중/후반) 운영 플랜, 라인별 상성**을 한눈에 확인할 수 있는 실시간 웹 도구입니다.

---

## 🚀 빠른 시작

```bash
cd lol-comp-web
npm install
npm run dev
```

브라우저에서 `http://localhost:5173` 접속!

---

## ✨ 핵심 기능

1. **OP.GG 스타일 직관적인 UI/UX**:
   - 블루팀 vs 레드팀 5:5 대치 레이아웃 (TOP, JUG, MID, BOT, SUP)
   - 조합 종합 승률 바 & 진단 헤드라인
   - 경고(⚠️ 올AD 주의, 앞라인 부재 등) 및 시너지(✨ 5인 한타 연계 등) 뱃지
2. **초고속 초성 검색 지원**:
   - 픽창의 촉박한 시간(30초) 속에서도 한글 초성으로 초고속 선택 가능
   - 예: `ㅇㅅㅇ` ➔ 야스오, `ㅁㅍㅇㅌ` ➔ 말파이트, `ㄹㅅ` ➔ 리 신, `ㅈㅋㅅ` ➔ 징크스
3. **5:5 한타 구도 집중 분석**:
   - 어느 팀이 한타에서 우위에 있는지, 5:5 정면 힘싸움(Front-to-Back) 승리 요인
   - 우리 팀의 한타 승리 플랜 및 상대팀 핵심 위협 스킬 대응법
4. **5대 핵심 스탯 비교**:
   - AD/AP 데미지 비율 게이지
   - CC & 군중 제어, 강제 이니시에이팅, 앞라인 탱킹, 원거리 포킹, 후반 왕귀력(스케일링)
5. **단계별 승리 플랜 (Macro Roadmap)**:
   - 1단계: 초반 (0~14분) 라인전 주도권 & 공허 유충 vs 첫 용 선택
   - 2단계: 중반 (15~25분) 1-3-1 스플릿 vs 5:5 강제 한타 매크로 스타일
   - 3단계: 후반 (25분~) 바론 버스트 & 장로 드래곤 엔딩 팁
6. **라인별 1:1 맞대결 상성 & 코칭 팁**:
   - 탑/정글/미드/원딜/서폿 맞대결 주도권 우열 판정 및 팁
7. **원클릭 프리셋**:
   - 유명 정석 조합, 올AD 암살 조합, 후반 왕귀 조합 등 원클릭 불러오기 및 진영 교체(Swap)
